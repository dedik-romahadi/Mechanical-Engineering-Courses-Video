# Mechanical-Engineering-Courses-Video

Video penjelasan materi untuk LMS Teknik Mesin, Universitas Mercu Buana
([dedik-romahadi.github.io/Mechanical-Engineering-Courses](https://dedik-romahadi.github.io/Mechanical-Engineering-Courses/)).

Repo ini hanya menyimpan berkas MP4 dan disajikan lewat GitHub Pages pada domain yang sama dengan LMS,
sehingga halaman modul memutarnya dengan jalur `/Mechanical-Engineering-Courses-Video/...`.
Video dipisah dari repo LMS supaya situs LMS tetap kecil dan deploy-nya cepat.
Situs GitHub Pages dibatasi 1 GB, jadi video dibagi ke dua repo: repo ini (Teknik Tenaga Listrik Modul 6–13)
dan [Mechanical-Engineering-Courses-Video-2](https://github.com/dedik-romahadi/Mechanical-Engineering-Courses-Video-2)
(Modul 1–5 dan 14).

| Folder | Isi |
|---|---|
| `Teknik-Tenaga-Listrik/` | Video penjelasan materi lengkap per modul (`Modul-N-Materi-<topik>.mp4`) |

Poster, halaman tonton, data bab, dan penghitung tayang ada di repo LMS
(`scripts/video-materi-data.mjs`, `Teknik-Tenaga-Listrik/Video/`).
